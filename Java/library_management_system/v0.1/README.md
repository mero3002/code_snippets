### Library Management System 0.1
Second mini-project discovering OOP in Java,
this is a simple stupid and ugly library system.

Admin can:
- Add book.
- Remove book.
- Register member.
- Remove member.
- Borrow book.
- Return book.
- Search books.
- Show books.
- Show members.
- Show borrowings.
- Quit app.

and yeah, the edge cases will mostly disappoint you.
### What to expect in 0.2
1. A better searching approach, the current one is horrible.
2. Try to reduce the need of synchronization between methods as much as possible.
3. Reduce code redundancy.
4. Better methods names.
5. Support multiple copies of the same book.
